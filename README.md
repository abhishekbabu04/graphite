# Graphite ✏️

Graphite is a Python-based web application that transforms uploaded images into pencil-style graphite sketches.

The application uses Claude AI during development and FastAPI for the backend, with OpenCV, NumPy, and Pillow for image processing to create a sketch effect from uploaded images.

## Features

- Upload an image
- Convert images into graphite/pencil sketches
- Fast image processing
- Simple web interface
- Gallery for generated sketches
- Python-based backend

## Tech Stack

- Python
- Claude AI
- FastAPI
- OpenCV
- NumPy
- Pillow
- HTML
- CSS
- JavaScript
